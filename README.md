# SmartProxy — Умный прокси для обхода блокировок

Программа для Windows, которая автоматически направляет трафик заблокированных сайтов через прокси-сервер в Латвии, а остальной трафик идёт напрямую.

## Статус

- ✅ **Сервер настроен** - 3proxy работает на 193.242.109.75:18388
- ✅ **Клиент готов** - Python скрипт для Windows

## Архитектура

```
┌─────────────────┐     ┌──────────────────┐     ┌─────────────────┐
│   Ваш браузер   │────▶│   SmartProxy     │────▶│  Сервер Латвия  │──▶ Заблокированные
│                 │     │   (локально)     │     │  (SOCKS5)       │    сайты
└─────────────────┘     │                  │     └─────────────────┘
                        │  Проверяет домен │
                        │                  │────▶ Напрямую ──────────▶ Обычные сайты
                        └──────────────────┘
```

## Быстрый старт (Windows)

### 1. Установить Python
Скачайте Python 3.10+ с [python.org](https://www.python.org/downloads/)
При установке **обязательно** отметьте "Add Python to PATH"

### 2. Скачать клиент
Скачайте или склонируйте репозиторий, вам нужна папка `client/`

### 3. Установить зависимости
```cmd
cd client
pip install PyYAML
```

### 4. Запустить SmartProxy
```cmd
python smartproxy.py
```

### 5. Готово!
**Никаких дополнительных настроек не нужно!**

Программа автоматически:
- Настроит системный прокси Windows
- Chrome, Edge и другие браузеры сразу начнут использовать SmartProxy
- При закрытии программы — всё вернётся как было

Просто откройте YouTube, ChatGPT или Gemini — они будут работать через сервер в Латвии.
Остальные сайты работают напрямую, без замедления.

## Сборка .exe (опционально)

Если хотите один исполняемый файл:

```cmd
cd client
build.bat
```

Готовый файл будет в `client/dist/SmartProxy.exe`

## Список проксируемых доменов

Редактируйте файл `client/config.yaml`:

- `gemini.google.com` и поддомены
- `notebooklm.google.com` и поддомены  
- `openai.com`, `chat.openai.com` и поддомены
- `youtube.com`, `youtu.be`, `googlevideo.com`
- `instagram.com`, `cdninstagram.com`
- `higgsfield.ai`

## Добавление новых сайтов

Откройте `config.yaml` и добавьте домены в раздел `domains`:

```yaml
domains:
  - "newsite.com"
  - "*.newsite.com"  # все поддомены
```

Перезапустите SmartProxy.

## Важно: Firefox

Firefox по умолчанию **не использует** системные настройки прокси. Для Firefox:

1. Откройте `about:preferences#general`
2. Прокрутите до "Параметры сети" → "Настроить..."
3. Выберите **"Использовать системные настройки прокси"**
4. Нажмите OK

После этого Firefox тоже будет работать через SmartProxy.

## Troubleshooting

### "Порт уже занят"
Измените порт в `config.yaml`:
```yaml
local:
  port: 8081  # или другой свободный
```

### "Ошибка подключения к прокси"
1. Проверьте интернет-соединение
2. Проверьте данные в `config.yaml`
3. Убедитесь что сервер работает:
   ```bash
   curl --socks5-hostname smartproxy:PASSWORD@193.242.109.75:18388 https://api.ipify.org
   ```

### Сайт всё ещё не работает
Добавьте все поддомены сайта в `config.yaml`. Используйте инструменты разработчика браузера (F12 → Network) чтобы увидеть какие домены использует сайт.

### При закрытии программы интернет не работает
Если программа была закрыта некорректно, настройки прокси могут остаться. Исправление:
1. Откройте "Параметры Windows" → "Сеть и Интернет" → "Прокси"
2. Отключите "Использовать сценарий настройки"
3. Или запустите SmartProxy снова и закройте корректно (Ctrl+C)
