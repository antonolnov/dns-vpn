БЫСТРАЯ УСТАНОВКА:
══════════════════

1. Установите Python (если ещё не установлен):
   → Скачайте с https://www.python.org/downloads/
   → При установке ОБЯЗАТЕЛЬНО поставьте галочку "Add Python to PATH"

2. Запустите install.bat
   → Дважды кликните на файл install.bat
   → Он установит всё необходимое и создаст ярлык

3. Готово!
   → Запускайте SmartProxy через ярлык на рабочем столе
   → Или через start.bat в этой папке


КАК ПОЛЬЗОВАТЬСЯ:
═════════════════

1. Запустите SmartProxy (ярлык на рабочем столе или start.bat)
2. Дождитесь сообщения "SmartProxy запущен и работает!"
3. Откройте браузер (Chrome, Edge) и заходите на нужные сайты
4. Для выхода нажмите Ctrl+C в окне программы


ЧТО БУДЕТ РАБОТАТЬ:
═══════════════════

• YouTube
• ChatGPT (chat.openai.com)
• Gemini (gemini.google.com)
• NotebookLM
• Instagram
• Higgsfield

Остальные сайты работают напрямую, без прокси.


ДОБАВИТЬ НОВЫЕ САЙТЫ:
════════════════════

Откройте config.yaml в текстовом редакторе и добавьте домены:

domains:
  - "newsite.com"
  - "*.newsite.com"

Перезапустите SmartProxy.


ПРОБЛЕМЫ:
═════════

Если что-то не работает:

1. Убедитесь что SmartProxy запущен (окно открыто)
2. Проверьте интернет-соединение
3. Для Firefox: настройте использование системного прокси
   (Настройки → Параметры сети → Использовать системные настройки)


ФАЙЛЫ:
══════

• smartproxy.py  - основная программа
• config.yaml    - настройки и список сайтов
• install.bat    - установщик
